# unreal-grpc-test

gRPC for an Unreal Engine 5.3 C++ frontend on RHEL 8, built with UE's own
Linux toolchain (clang 16.0.6 + UE libc++).

- [docs/PLAN.md](docs/PLAN.md): plan for the automated build (for review)
- [docs/BUILD_GRPC_UE53_RHEL8.md](docs/BUILD_GRPC_UE53_RHEL8.md): step-by-step manual build and UE integration guide
- [docs/WINDOWS_RHEL8_TEST_ENV.md](docs/WINDOWS_RHEL8_TEST_ENV.md): a RHEL 8-compatible environment on Windows (WSL2 + AlmaLinux 8) for fetching UE Linux files and testing
